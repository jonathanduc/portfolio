Recipes & Nutrition - Data Integration API

Projet en binôme d'intégration de données combinant des informations de recettes et de nutrition provenant de plusieurs APIs.

Node.jsExpressSwaggerSpoonacularOpen Food FactsHTML/CSS/JS

  • Retour aux projets
  • GitHub

Context & Objective

Agréger des sources hétérogènes dans une API commune afin de rechercher des recettes, consulter leurs ingrédients et enrichir les informations avec des données nutritionnelles.

Approach

Le backend Node.js/Express orchestre les appels à Spoonacular et Open Food Facts. Une documentation Swagger facilite l'exploration des endpoints et une interface web légère permet de consulter les résultats.

Implementation

Le projet met l'accent sur la consommation d'APIs externes, la normalisation des réponses et la construction d'une couche de service cohérente pour le frontend.

What I Learned & Progression

Ce projet est une première expérience concrète d'architecture API et d'intégration de données connectées, antérieure à mes travaux professionnels sur des services Python et REST.

Ce que ce projet démontre

Capacité à structurer un problème, choisir une approche adaptée, documenter les choix techniques et communiquer les résultats sans masquer les limites.
