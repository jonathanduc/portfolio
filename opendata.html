Open Data Dashboard - OMS

Dashboard interactif construit autour d'indicateurs de santé publique de l'Organisation mondiale de la Santé via l'API GHO.

Context & Objective

Explorer des indicateurs de santé publique dans une interface interactive et combiner visualisation, analyse statistique et Machine Learning exploratoire.

Approach

Le projet comprend des visualisations interactives, une régression linéaire pour la prévision, une analyse PCA suivie de KMeans pour profiler les pays et des cartes choroplèthes.

Implementation

Les données sont récupérées depuis l'API OMS/GHO, puis préparées dans un pipeline Python avant d'être exposées dans Streamlit.

What I Learned

Ce projet m'a permis de travailler la chaîne complète allant de l'Open Data à une application d'analyse destinée à l'exploration.

Ce que ce projet démontre

Capacité à structurer un problème, choisir une approche adaptée, documenter les choix techniques et communiquer les résultats sans masquer les limites.
